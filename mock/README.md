# Mock Directory

## Purpose

This directory contains static HTML mockups created during Phase 1-2 to establish UI/UX specifications before implementing the React frontend.

## Contents

- `index.html` — Full-page mockup of the Course Finder UI including:
  - Navigation bar with auth state
  - Course search with filters (level, organization, skills, rating)
  - Course cards in grid layout
  - Recommended courses section
  - Responsive design specifications

## Usage

These mockups served as the design reference for the React + MUI implementation in `frontend/`. They are preserved for historical reference and design traceability.

## Status

- Design specifications extracted and implemented in React
- Preserved as reference (not actively maintained)
